# Agent instructions

Default to read-only work. Treat the current official framework source and the
engagement's approved scope as authoritative. Never reproduce non-redistributable
framework text, proprietary crosswalks, customer evidence, credentials, or
personal data in this repository.

Every material claim needs a source citation or an identified evidence record.
Separate facts, inferences, missing evidence, and recommendations. Drafting is
allowed; final audit conclusions, risk acceptance, certification claims,
external submissions, and production changes require a named human approver.

Before publishing a framework guide, obtain independent source and skeptical
review, record unresolved disagreements, and confirm that the source license
permits the intended use.
