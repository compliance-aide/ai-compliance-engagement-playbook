# AI Compliance Engagement Playbook

Open, source-linked operating guidance for AI-assisted, year-round compliance
engagements. It helps a team organize work for a framework without replacing
the framework publisher, a qualified auditor, legal counsel, a system owner, or
an authorized signer.

## What this repository is

- A repeatable lifecycle for planning, operating, assessing, and renewing a
  compliance engagement.
- Guardrails for AI agents that assist system operators and independent
  assessors.
- Reusable records for evidence, tests, findings, remediation, and decisions.
- A publication workflow for framework guides that starts with official sources.

## What it is not

It is not a certification, legal advice, an audit opinion, an authorization to
accept risk, or a substitute for an applicable framework or assessor method.
AI must not make attestations, submit declarations, accept risk, or alter
production systems without the approval specified in the engagement charter.

## Start here

1. Read [the operating model](docs/operating-model.md).
2. Follow [the AI-agent execution protocol](docs/ai-agent-execution-protocol.md)
   to keep computer use, evidence, operator support, and auditor support separate.
3. Create an engagement charter from [the template](templates/engagement-charter.md).
4. Follow the [source research policy](docs/source-research-policy.md) before
   creating or updating a framework guide.
5. Use [the framework template](docs/framework-template.md), then obtain
   independent review and named human approval before publishing it.

## Framework guides

The repository deliberately does not republish copyrighted standards,
proprietary crosswalks, or derived mappings. A framework guide may be added
only when it is grounded in official, redistributable sources and its license,
edition, scope, and reviewer are recorded. See the [framework index](docs/frameworks/INDEX.md).
