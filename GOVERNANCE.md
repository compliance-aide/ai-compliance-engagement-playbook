# Governance and source boundary

This project publishes original operational guidance only. It does not publish
or transform framework text, proprietary mappings, customer evidence, or a
publisher's licensed dataset unless a maintainer has recorded written permission
for that exact use.

Framework names are used only for nominative reference. Names and marks belong
to their respective owners. A guide must not imply endorsement, affiliation,
certification, or assessor status.

Before publication, a named reviewer must confirm the authoritative source,
edition, source license, source links, the guide's factual accuracy, and that
the guide contains no copied or derivative restricted content.
