# ISO/IEC TS 27008:2019 control assessment — engagement guide

> Original operational guidance, not ISO content or a control conclusion. Confirm the [ISO technical-specification record](https://www.iso.org/standard/67397.html) and its review status; do not place ISO text in AI prompts.

## Engagement focus

Maintain assessment objectives, local criteria, system boundaries, technical test records, observations, evidence provenance, exceptions, corrective actions, and retest results.

## Roles and annual rhythm

Technical owners validate system reality; qualified assessors define methods and conclude independently. AI organizes artifacts and highlights gaps, but cannot set criteria, test systems, or declare compliance. Assess material changes, sample quarterly, and review annually.

Apply the [universal engagement contract](../universal-engagement-contract.md) for the shared applicability, authority, evidence, technical-test, exception, source-change, and renewal requirements that govern this framework engagement.
