# ISO/IEC 27033 network security — engagement guide

> Original operational guidance, not ISO content or a network-security design approval. Check the [ISO/IEC 27033-1 record](https://www.iso.org/standard/63461.html); do not place ISO text in AI prompts.

## Engagement focus

Maintain architecture scope, network assets and flows, design decisions, segmentation evidence, gateway and remote-access records, monitoring, changes, exceptions, supplier dependencies, and test results.

## Roles and annual rhythm

Network and security owners approve architecture and changes; independent reviewers test representative paths. AI builds evidence maps and finds drift, but cannot configure networks or approve designs. Review material changes, sample quarterly, and assess annually.

Apply the [universal engagement contract](../universal-engagement-contract.md) for the shared applicability, authority, evidence, technical-test, exception, source-change, and renewal requirements that govern this framework engagement.
