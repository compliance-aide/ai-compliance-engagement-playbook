# ISO/IEC 27034 application security — engagement guide

> Original operational guidance, not ISO content or a software assurance claim. Check the [ISO series record](https://www.iso.org/standard/44378.html); do not place ISO text in AI prompts.

## Engagement focus

Maintain application portfolio, security context, lifecycle evidence, requirements decisions, supplier dependencies, engineering tests, release approvals, vulnerability handling, and exception records.

## Roles and annual rhythm

Product, engineering, and security owners approve application decisions; independent reviewers sample delivery evidence. AI links work items, changes, tests, and releases, but cannot approve a release or make assurance claims. Review each release cycle and annually.
