# EU Cloud Code of Conduct — engagement guide

> Original operational guidance, not adherence or certification. Confirm live status at the [EDPB code register](https://www.edpb.europa.eu/our-work-tools/accountability-tools/register-code-of-conduct/2021/eu-cloud-code-conduct_pl).

## Engagement focus

Maintain service role, agreements, subprocessor, customer-assistance, incident, location/transfer, deletion, notice, and renewal evidence.

## Roles and annual rhythm

Qualified humans decide interpretation and adherence; independent reviewers sample operations. AI identifies inconsistency among commitments and evidence, but cannot declare adherence or engage monitoring bodies. Review quarterly and annually.


## Universal engagement contract

Apply the [universal engagement contract](../universal-engagement-contract.md) for the shared applicability, authority, evidence, technical-test, exception, source-change, and renewal requirements that govern this framework engagement.
