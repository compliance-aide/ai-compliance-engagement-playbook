# Copyright and source policy

Each framework guide uses original language and an independently researched,
official source. It must not be generated from the Secure Controls Framework
crosswalk, copied framework text, mapping tables, assessment objectives, or any
other restricted source material.

Before adding a guide, a contributor records the official source, edition,
retrieval date, rights note, and reviewer in `SOURCES.md`. The guide may name a
framework for nominative reference, but it may not use logos, seals, claims of
endorsement, or language suggesting certification.

If a source has terms that prohibit AI use, copying, transformation, or public
redistribution, the contributor may link to it but must not use it to generate
source-derived content for this repository. A maintainer must resolve any doubt
before merge.
